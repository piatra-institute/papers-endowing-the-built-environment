# Endowing the Built Environment

A financial and institutional argument about committing assets to a building's recurring renewal. A matched-resource lifecycle model leads into a proposal for a worldwide steward with separate client assets, explicit fees and replaceable management.

[Read the paper](paper/PAPER.pdf) · [Manuscript](paper/PAPER.md) · [Study and reproduction](simulation/README.md)

October 2026 edition. Available in the [institute's papers catalog](https://piatra.institute/papers) and as a [direct PDF](https://piatra.institute/papers/endowing-the-built-environment.pdf). Publication does not indicate external peer review.
